Nova

一个本地桌面客户端。你选项目、下任务，AI 就在你电脑上替你干活，所有过程实时显示在界面里。

Nova 是什么

你像老板：选项目、下任务、审过程与结果。AI 在本地 shell 里干活——思考、工具调用、文件改动、终端输出都实时显示在界面上。除了「你戳一下它动一下」的用法，Nova 还能配置一批常驻数字员工替你持续推进工作。

主界面分三块：左侧侧边栏（会话列表 + 视图切换），中间主区域（首页或会话视图），按需弹出各种弹窗（设置、成就、收件箱、更新等）。

5 分钟上手

1

装好至少一个 AI 后端的命令行工具，并在终端登录一次。例如 devin、codex、claude 等。Nova 启动时会自动检测哪些后端可用。

2

启动 Nova。默认进入首页，正中是大字标题「我们该做什么？」，下面是一个任务输入框。

3

选项目：点输入框下方工具条左侧的「项目」胶囊按钮，弹出列表里挑一个最近项目；也可以点列表底部的「使用现有文件夹…」浏览任意目录；或选最上方的「临时会话（不使用项目）」在系统临时目录建一个空工作区。

4

选后端和模型：点项目胶囊右边的「模型」胶囊。如果只启用了一个后端，弹出二级面板：左栏列厂商（如 OpenAI、Anthropic），右栏列该厂商的模型，鼠标移到左栏某项右栏跟着切换。如果启用了多个后端，弹出三级面板：最左栏列后端（Devin、Codex、Claude Code 等），中栏列厂商，最右栏列模型。顶部有搜索框可直接搜模型名。模型右侧会显示单价（如 $5/$25）和支持图片的眼睛图标。点模型即选中。

5

输入任务，回车发送。界面立即切到会话视图，AI 开始干活，过程实时滚动显示。任务跑完会弹系统通知（如果窗口不在前台）。

提示：如果侧边栏某个后端显示「未检测到 CLI」，说明对应命令行工具没装或不在 PATH 里。可去「设置 → 模型后端」对应卡片的「可执行文件」里填完整路径，保存后会自动重新检测。

下达第一个任务

首页从上到下依次是：

  • Logo + 标题「我们该做什么？」
  • 任务输入框（多行文本域，自动增高，最高 220px）
  • 工具条（输入框下方一行按钮，从左到右）：
    • 项目胶囊：显示当前项目名，点开选项目。
    • 模型胶囊：显示当前后端/模型，点开切换。
    • 工作流图标按钮（分支图标）：点开选一个已启用的工作流来运行本次任务，不选就是普通会话。菜单里每项标注「内置 / 自定义 / 团队 · 队友名」和节点数。
    • 证据链图标按钮（线索图标）：跳到证据链页面，从线索发起会话或查看当前引用的线索。
    • 数字员工图标按钮（人头图标，配了员工才出现）：点开选本次工作交给哪个员工，菜单里每项标注「工作流名 · Dream 生效」。
    • 发送按钮（纸飞机图标）。
  • 最近会话列表（工具条下方）：最多 6 条，点一下直接打开。

三个发送快捷键：

Enter
发送，开始新会话。
Ctrl/⌘+Enter
创建临时会话（标「临时」徽章，程序关闭时自动删除）。
Alt+Enter
在 git worktree 中执行（弹窗填分支名，详见下文）。仅当前目录是 git 仓库时可用。

输入框为空时，占位符会提示当前模式：描述任务，Enter 发送 · Ctrl+Enter 临时会话 · Alt+Enter 在 worktree 执行。

输入框的全部技巧

输入 /
弹出斜杠命令菜单。↑↓选择、Tab 或 Enter 插入，Esc 关闭。
空框按 ↑
弹出历史输入菜单（你之前发过的提示词，含图片附件数量）。↑↓选择、Tab/Enter 插入。
空框按 ↓
恢复上次未发送的草稿（含图片附件）。
Shift+Enter
换行。
直接粘贴 / 拖入文件
图片作为附件显示在输入框上方的附件条；可多张，点 × 删除。
Ctrl+Shift+V
把剪贴板里的文件作为路径文本插入（不作为附件）。适合把文件路径告诉 AI。

任务运行中再输入会怎样

回车会把新提示词加入「待发送队列」，输入框上方出现队列条目（带序号、文本预览、附件数）。每条右边两个按钮：

  • 撤回（撤销图标）：把这条拿回输入框，可改后再发。
  • 发送（纸飞机图标）：立即作为引导发送。支持引导的后端（Vega、Lyra、Codex、Devin、Cursor、OpenCode）可在运行中直接插入；不支持的按钮会置灰。

队列头部提示「当前任务结束后自动发送」或「已停止，可手动发送或撤回」。空输入框按 Enter 也会立即发送队列第一条作为引导。

斜杠命令速查

输入 / 弹出菜单，列出 Nova 内置命令和当前后端自带的命令。内置命令：

命令怎么用
/plan让 AI 先出一份待办清单（计划卡片），不直接编码。计划结束后会弹「实施此计划？」卡片，点「是，实施此计划」即按计划开始编码，点「否」放弃。
/easy显而易见的小修改：不运行或编写测试，仅做基本编译校验。
/stage用配置的 Stage 模型开启一个新会话，引用当前会话作为前置内容。/stage 等同 /stage1，可在「设置 → 通用 → Stage 模型」配置 /stage2、/stage3… 用的模型。
/fire分阶段执行，并用独立会话反复验收直到目标达成。配合 /target 明确验收规则。
/target为 /fire 明确指定验收规则，需与 /fire 一起发送。
/run 工作流名 目标运行一个已配置的工作流。例如 /run 评审 修复登录页。可用 -- 附带自定义变量：/run 评审 修复登录页 -- criteria=不能有类型错误。
/train立即用大熊座配置的模型训练一次经验库。训练完弹窗告诉你新学了几条经验，并自动跳到大熊座视图。
/setup 模型名把一个模型 / provider 接入 Vega。

管理你的会话

侧边栏从上到下：

  • 顶部品牌区：Nova logo + 版本号（点一下静默检查更新）。右边一排小徽章：
    • 中转站徽章（广播图标 + 在线人数）：配了团队中转站才出现。鼠标悬停弹出本群组在线名单，自己置顶标「我」。
    • 收件箱徽章（铃铛图标 + 数字）：有人 Flow 给你时出现，点一下打开收件箱。
    • 更新徽章（下载图标 / 转圈）：新版本下载中转圈，下载完变下载图标，点一下打开更新弹窗。
  • 新对话按钮：回到首页开新会话。
  • 视图切换（两行标签）：上行「普通模式 / 工作流 / 证据链」，下行「大熊座 / 御书房 / 数字员工」。带未读角标（如御书房显示候旨+进行中数，证据链显示新提醒数，工作流显示待接收分享数）。
  • 会话列表：默认按项目目录分组（可在「设置 → 通用」改成按时间排列）。每组顶部是目录名（右键菜单：在终端/资源管理器打开），右侧有垃圾桶批量删除该目录下会话。组内超过 5 个会话会折叠，点底部箭头展开。
  • 底部：设置（齿轮）、成就（奖杯，有新成就显示数字角标）。

会话条上的标记

  • 后端徽章（如 D、Cx）：显示 Wake 用的后端。预检 → 开发子会话会显示成对徽章和箭头 D → Cx。
  • worktree 分支：⎇ feature/login，表示在独立 worktree 执行。
  • 预检 · N：该预检会话下有 N 个开发子会话。
  • 临时：临时会话，程序关闭时自动删除。
  • 时间：今天显示时分，其他显示月日。
  • 垃圾桶：删除该会话（运行中的会话不能删）。

会话右键菜单

  • worktree 会话：「合并到分支…」「在终端中打开 worktree」「在资源管理器中打开 worktree」。
  • 普通会话：「在终端中打开」「在资源管理器中打开」。
  • 漫游会话（队友目录）：显示「队友的目录，无法在本机操作」。
记忆延续：应用重启后，之前的会话会自动恢复上下文，可以接着聊。会话历史保存在本地 ~/.nova/ 目录下。

看懂 AI 的工作过程

会话视图从上到下：顶栏（标题+按钮）→ 中间对话区（滚动）→ 底部输入框。对话区里每条内容：

  • 你的消息：右对齐圆角块。鼠标悬停右上角出现铅笔图标，点一下可编辑这条消息并从这里重新开始（后续内容全部作废，相当于 git reset）。编辑时可改文本、管理附件，Enter 发送。
  • AI 的回复：左对齐正文，Markdown 渲染。代码块右上角有复制按钮（点一下变 ✓）。正文里出现的文件路径会变成可点击的按钮：单击在配置的编辑器里打开（带行号），右键「打开所在目录」。图片文件单击用系统默认程序打开。
  • 思考过程：可折叠块，默认折叠。点「思考过程」展开看 AI 的推理。
  • 工具调用：紧凑一行——图标 + 标题 + diff 统计（+N -N）+ 耗时 + 状态点（转圈=进行中，红点=失败）。点整行展开详情：
    • 命令执行：显示输出（带复制按钮）。
    • 文件编辑：显示 diff 视图，左绿右红。文件路径可点击在编辑器打开，右键「打开所在目录」。
    • 位置芯片：涉及的文件位置（文件名:行号），点击跳转编辑器。
    • 原始数据：点「原始数据」可看工具的原始输入/输出 JSON。
  • 已编辑文件卡片：每个回合结束如果改了文件，底部出现「已编辑 N 个文件 +X -Y」卡片，列出每个文件路径和增删行数。点文件在编辑器打开。右上角「撤销」按钮：把这些文件恢复到本轮编辑前的内容（被后续修改过的文件会跳过），撤销后按钮变「已撤销」。
  • 回合折叠：长回合中间过程会折叠成一行（如「12 个工具调用 · 1.2k tokens」），点展开。

审批 AI 的敏感操作

当后端要执行敏感操作时，对话区底部弹出一张审批卡片。两种形态：

按钮审批

卡片标题形如「Devin 请求权限：执行工具」，下方 pre 块显示操作预览（命令、路径等）。底部一排按钮是后端动态返回的选项（例如「允许一次」「总是允许」「拒绝」等，具体文案以后端为准）。点哪个就按哪个响应。

问答审批

卡片标题形如「Devin 需要确认：…」，下面列出若干问题。每题有候选选项按钮（单选点一个即选中，多选可点多个），每个选项下可能有小说明。如果该题允许自定义答案，下方有「输入其他答案」输入框。全部回答后点「提交回答」；也可「拒绝回答」。

让 AI 先出计划再动手

发送 /plan 你的任务。AI 会先产出一份待办清单，对话区显示「计划」卡片：标题旁有进度「已完成 / 总数」，每条带状态点（完成/未完成）。点标题可折叠/展开清单。

计划结束后（任务停止运行时），输入框上方弹出「实施此计划？」卡片：「按计划开始编码，或继续用 /plan 补充规划。」两个按钮：

  • 是，实施此计划：AI 按计划开始编码。
  • 否：放弃，可继续用 /plan 补充规划。

会话顶栏按钮一览

打开会话后，顶栏从左到右依次是：

  • 标题：双击进入重命名模式，Enter 保存，Esc 取消。
  • 星标（星形按钮）：加星后在该项目内置顶。
  • 后端徽章：如 Devin、Codex。
  • 漫游徽章（仅漫游会话）：guest 显示「漫游 @ 队友」（在对方机器执行），host 显示「代执行 · 队友」（替对方在本机执行）。
  • 额度徽章（仅额度会话）：「额度 · 队友」（临时借用对方加密授权额度）。
  • 工作目录：普通会话显示路径；worktree 会话显示「仓库名 ⎇ 分支」。
  • 累计 tokens：鼠标悬停看明细（按输入/输出/缓存拆分）。
  • 压缩按钮（仅 Codex 后端）：把当前长历史浓缩为摘要，后续仅基于摘要继续，加快响应。
  • Flow按钮：把当前会话分享给队友（详见下文）。
  • 召回按钮（仅 guest 漫游会话）：把这段漫游会话拿回本机，对方自动回传完整快照。
  • 世界线入口（右侧时钟图标，展开后显示）。

底部输入框上方还有：

  • 运行状态条（运行中显示）：圆点 + 已运行时长 + 「上下文 X / Y tokens」。鼠标悬停看明细。
  • 证据链按钮（线索图标）：本会话引用了线索时高亮，点一下跳到证据链。
  • 数字员工选择器（人头图标，仅新普通会话且配了员工才出现）。
  • 停止按钮（方块图标，运行中才显示）：点一下停止。普通会话直接停；员工会话弹「停止数字员工」对话框，可填停止原因告诉 Dream，点「直接停止」或「提交原因并停止」。
  • 发送按钮（纸飞机图标）。

工作流运行到「人工审核」节点时，输入框上方还会出现「等待人工审核 · 选择下一步」横条，列出可选的下一步连线按钮，点哪个走哪条线。

世界线：回到任何一个时间点

每个会话有一条时间线，记录你每次发送提示词后产生的工作目录快照（Checkpoint）。点顶栏右侧的时钟图标展开「世界线」侧栏：

  • 节点图：每个圆点是一个时间点，上面的数字是该时间点的提示词数量。当前时间线上的节点高亮，分叉的节点用不同颜色。成功/失败结果用不同颜色区分。
  • 点节点：跳转到那个时间点——预览该时间点的会话历史。如果开了 Checkpoint（见下），还会把工作目录文件还原到对应时间点。顶部出现「回到当前时间线」横条，点一下回到最新。
  • 右键节点：菜单可「标记成功/失败/清除结局标记」（结局标记会作为时光笔记的提示），以及各种删除上下文操作（删除到开始/向上 N 个/自身/向下 N 个/删除到结尾）。
  • 时光笔记按钮：弹窗填 skill 名称、选训练后端和模型，确认后新开一个训练会话，自行阅读这条世界线的成败历史并逐级分析，沉淀为可复用的 skill。
Checkpoint 还原需在「设置 → 高级 → 世界线 → 启用 Checkpoint」开启。开启后从其他时间线继续对话会把工作目录文件还原到对应时间点，请谨慎使用。默认关闭时只切换会话历史，不修改当前文件。

在独立分支里干活

想让 AI 在独立分支目录里干活、不污染主工作区？在首页输入框写好任务后按 Alt+Enter，弹出「在 worktree 中执行」对话框：

  1. 新分支名（可留空）：填新分支名（如 feature/login）= 基于所选分支切新分支；留空 = 直接使用下面所选分支（不能是已检出的分支）。
  2. 基于分支：可搜索/手填的下拉，默认当前分支。点开列出所有分支，当前分支标「当前」。
  3. 点「创建并执行」（填了新分支名）或「在所选分支执行」（留空）。

会话在独立 worktree 目录执行，侧边栏会话条显示 ⎇ 分支名。

合并回主分支

右键 worktree 会话 →「合并到分支…」→ 弹窗列出可选目标分支，点选一个 → 点「合并」。若产生冲突，会自动交给该会话的 AI 解决并完成合并提交。合并前请确认 worktree 里的改动都已提交。

集中管理

所有 worktree 在「设置 → Worktree」里集中管理：查看分支、关联会话、移除（可选「同时删分支」；直接检出已有分支的 worktree 移除时不删分支）。这些工作目录不随会话删除而自动清理。

六大视图

侧边栏两行标签切换六个视图：

普通模式

默认视图，列出你自己的会话，按项目分组。日常下达任务、看过程、审结果都在这里。

工作流

可视化的工作流编排器。左上角悬浮「工作流列表」按钮（显示当前工作流名），点一下展开左侧抽屉：

  • 新建按钮：创建一个空工作流。
  • 导入按钮（连了中转站才出现）：导入队友共享的工作流，有待接收会显示数字角标。
  • 删除按钮：删除选中工作流（内置的不能删）。
  • 工作流列表：内置标「内置」徽章，队友分享标「团队」徽章，停用的标「已停用」。点一下选中并关闭抽屉。
  • 底部「从内置复制：」可克隆内置工作流作为起点。

选中工作流后，右侧画布显示节点图。画布上方浮动工具条：

  • 名称输入框：改工作流名（内置的禁用）。
  • 已启用/已停用芯片：点击切换。停用后不出现在新会话选择和 /run 中。
  • 编辑按钮：编辑选中的阶段或连线（也可双击节点/连线）。
  • 阶段按钮：添加一个新阶段节点。
  • 撤销：放弃未保存改动。
  • 保存：保存改动。
  • 共享到团队 / 撤回共享（连了中转站才出现）。

画布操作提示（右下角浮动）：双击节点/连线编辑 · 拖右侧手柄连线 · 右键删除 · 滚轮缩放。

编辑阶段

双击节点或选中后点工具条「编辑」，弹出阶段编辑窗：

  • 阶段名称输入框 + 「设为首节点」按钮。
  • 人工审核勾选框：开启后节点完成时暂停，不由模型判断去向；用户在会话底部手动选下一步连线。
  • 模型选择器：默认「跟随会话」，可选指定后端/模型。
  • 提示词模板：支持占位符 {{goal}}（启动时填的目标）、{{prev}}（上一节点结论）、{{attempt}}（第几次进入）、{{criteria}} 等自定义变量。
  • 底部「删除该阶段」按钮。

编辑连线

双击连线弹出：连线名称（显示在线上）+ 跳转依据（告诉引擎什么情况下走这条线，留空则用连线名称）。去向由提示词判断：引擎把跳转依据隐式插进前一节点的提示词，要求它标明所选去向；未明确则由轻量模型按结论判断。

运行工作流

两种方式：在首页输入框点工作流图标按钮选一个，或在会话里输入 /run 工作流名 目标。

证据链

像刷微博一样浏览「线索」：点卡片原地展开全文与回帖，线索之间的连接以回帖形式呈现。右上角：

  • 个人空间 / 团队空间切换：个人空间始终本地保存；团队空间通过中转站共享（需先连接）。团队空间按钮未连接时置灰。
  • 新建线索按钮：弹出线索捕获窗（见下）。

线索卡片

每张卡片：作者头像 + 时间 + 版本号 vN + 标题 + 摘要。点卡片展开全文。底部操作行（灰字横排）：

  • 回帖数（或「回帖」）：点一下展开回帖楼层。
  • N 接力：回复本条的下一条线索，点一下跳过去。
  • N 附件 / N 提醒 / 新提醒：附件可点击打开/下载；@ 提醒的成员高亮。
  • 连接：点一下进入连接模式，再点另一张卡片即建立连接（回帖关系）。
  • 回复线索：弹出线索捕获窗，默认「堆叠线索」。
  • 发起会话：以这条线索作为上下文开一个新会话。
  • 更新：弹出线索捕获窗，默认「更新旧线索」。
  • 删除：删除该线索。

展开后的回帖区

线索捕获窗

三种去向按钮：

  • 更新旧线索：选一条已有线索，给它加新版本。
  • 堆叠线索：在同一组里加平行线索。
  • 开启新线索：新建一条独立线索（可选前置线索，下拉里选「不接前置线索」则无前置）。

下方：线索标题输入框 + 线索内容文本域（可直接粘贴图片或文件，也可「添加附件」按钮选本地文件）+ @ 提醒选择器 + 「保存线索」按钮。从会话里打开时还有「AI 总结」按钮（用轻量模型总结会话核心内容）和「保存空间」选择（个人/团队）+「与同会话线索堆叠」勾选框。

数字员工

配置你的常驻 AI 员工。左侧员工列表（绿点=在岗，灰点=休息；显示后端徽章、心跳周期或「手动」或「休眠中」），右侧详情。右上角「去御书房」和「新建员工」按钮。

新建/编辑员工弹窗

  • 名字：如「后端小助手」。
  • 工作模型：和新会话一样的后端/模型选择器。运行权限固定 Build（全自动）；需规划时在会话里用 /plan。
  • 允许员工使用独立 git worktree勾选：只控制能力边界，员工自己决定用不用。
  • 工作流下拉：选已配置的工作流。默认内置「开工预检 → 开发（Wake → Do）」。
  • 岗位说明书（启动提示词）：定义它是谁、负责什么、工作规范与偏好。
  • 自动心跳勾选：开启后定时巡查、自动领活；关闭则只在御书房交办或朱批时行动。
  • Dream 模型：独立于 Wake，只在员工没工作且有新事件时反思学习、合并经验、降级低价值记忆。
  • 开了心跳才显示：心跳周期（秒，有预设按钮）+ 巡查/心跳模型（建议选便宜的）+ 上班时间勾选（开启后设时段和星期，时段外自动休眠；跨夜班可设 22:00 至 06:00；不选任何星期=每天都上班）。
  • 创建后立即上岗勾选：到点自动干活。
  • 常驻职责：去哪里找、找什么样的单子、怎么算完成。留空则只处理你登记到账本的单子。
  • 协作账本 scope：多个员工填相同 scope 即可对同一批单子去重、互斥认领、失败接力。
  • 共享到中转站勾选：同组队友填相同 scope 时共用一个账本，跨机器去重/互斥/接力。
  • 讨论伙伴：本机其他员工（勾选）+ 跨机队友伙伴（填队友展示名 + 对方员工名，可添加多个）。

员工详情页

  • 顶部：名字 + 后端徽章 + 「动态工作目录」+ 心跳周期/「手动指派」+ 上班时间 + 工作流名 + 「休眠中」徽章（非上班时段）。右侧按钮：停用/启用、编辑（齿轮）、解雇（垃圾桶）。
  • 常驻职责区块：显示职责正文 + 账本 scope + 讨论伙伴。
  • Dream区块：状态（运行中/暂停/冷却/空闲）+ 待处理事件数 + 记忆数/上限 + 保护数。按钮：暂停/启用/恢复。
  • 记忆 / 知识库区块：
    • 「添加知识」按钮：弹出文本域，写清适用条件和结论，保存为人工知识。
    • 分类标签：全部 / 人工 / Dream / 长期（带数量）。
    • 每条记忆：徽章（人工/Dream/长期）+ 任务标题 + 时间。右侧按钮：点赞（Dream 优先保留强化）、点踩（Dream 优先复核修正降级）、设为长期知识（图钉）、编辑、删除。人工分类不显示点赞点踩。

北斗七星专家

画面上七颗星代表七个独立经验专家（参宿一~七，对应 fast/concrete/balanced/abstract/negative/novel/slow 七种认知视角）。每颗星按真实恒星参数渲染（大小、色温、闪烁）。星上有未评分经验数会显示红色数字角标。点一颗星选中，下方显示该专家产出的经验条目：

  • 每张经验卡：类型标签（经验/记忆/守则）+ 泛用/项目独有 + 更新日期 + 触发条件 + 动作 + 避免（如有）+ scope + 置信度。
  • 底部反馈按钮：↑ 有用（再点取消）、↓ 有问题（再点取消）、删除。反馈会调整经验权重。

团队协作

连接团队中转站

「设置 → 团队」里配置：

  • 中转服务地址：一般用默认（留空回退默认）。
  • 身份 token：填服务端为你配置的 token。旁边「验证」按钮可测试连接。填了 token 即开启团队/漫游，清空 token 即关闭。
  • 群组：逗号或空格分隔，可多个。只有相同群组的人才能在在线名单里看到彼此、互相分享/漫游。留空 = 默认群组。

连接后侧边栏顶部出现中转站徽章，鼠标悬停看本群组在线名单（自己置顶标「我」）。

漫游到队友的机器

先在「设置 → 团队 → 允许漫游的项目」里添加你想对外开放的本地项目（每行一个，用 ProjectPicker 选；未列入的目录不会展示给队友）。队友就能在他的首页项目选择器里选你的目录发起漫游会话——每次请求仍需你在本机确认。

两种漫游方向：

  • guest 漫游：你在队友的机器上执行，本机只接收过程展示，只读。会话顶栏显示「漫游 @ 队友」。可点「召回」把完整快照拿回本机（对方自动回传，到你的收件箱选项目接收）。
  • host 代执行：队友的活儿在你本机执行，你替对方跑。会话顶栏显示「代执行 · 队友」。

「允许 server 端远程控制」默认关闭。手动开启并保存后，server 端才可查看会话、读取项目文件或发送远程操作。可点「远控二维码」生成二维码用手机扫码打开远控页面。

把会话 Flow 给队友

会话顶栏点「Flow」按钮弹出分享窗，顶部三个标签：

  • 线索（默认）：嵌入线索捕获窗，把会话结论保存为一条线索分享。可选个人/团队空间、与同会话线索堆叠、AI 总结。
  • 快速分享：直接把当前对话原样分享给队友。下方选队友（列出在线/离线状态），点「分享」。
  • 高级分享：先用模型按你的提示词处理会话（如总结要点），把结果分享给队友。需填处理提示词、选处理模型、选队友，点「处理并分享」。处理过程会在本机新开一个会话，跑完自动发送。

接收 Flow

队友分享给你时，侧边栏顶部出现收件箱徽章。点开收件箱弹窗，每条显示：后端徽章 + 标题 + 来自谁 + 时间 + 消息数。点「接收到…」展开项目选择列表（可搜索、可选临时目录、可浏览其它文件夹），选一个即变成你的本地会话。召回的漫游会话会标「召回」徽章。也可「忽略」。

共享你的模型额度

「设置 → 团队 → 共享模型额度」里添加你想共享的模型（每行一个，用 ModelPicker 选）。共享的模型会以「我的 Cursor」这类一级分类出现在队友的新会话模型选择器中。队友选用时，临时借用你的加密授权额度在本机目录执行。首次添加会安全同步并预热额度租约。队友发起额度会话时会弹「正在准备额度会话」加载窗，可「取消本次漫游」。

设置详解

侧边栏左下角「设置」按钮打开，顶部十个标签页：通用、高级、模型后端、Agent 配置、外观、团队、记忆检索、Worktree、Skills、关于。底部「取消」和「保存」按钮。

通用

会话

  • 会话历史展示方式下拉：按项目（默认）/ 按时间。按时间会将普通会话按最近更新时间排列，并标出项目和模型。
  • 编辑器命令：点击文件路径时用它打开，如 code / cursor / zed / windsurf（需在 PATH 中）。
  • 自动清理过期会话勾选 + 会话保留时间（小时）：启用后启动时及每小时检查，超时先移入回收站，保留同样时长才彻底删除。周六周日不计入保留时长。仅清理普通会话。
  • 会话快捷键：点「添加」录制。每行：按键（点一下按钮进入录制，按组合键即录下，Esc 取消）+ 动作下拉（选择模型/选择项目/快速新会话/快捷输入）+ 目标（按动作不同显示模型选择器/项目选择器/文本框）。可删除。默认 Esc 终止当前回合。

轻量级模型

  • Stage 模型：按顺序配置 /stage、/stage2、/stage3… 用的模型。每行一个 ModelPicker，可移除。下方可添加新行。
  • 轻量级模型：用于标题生成、快速总结、摘要和上下文压缩等辅助任务；调用失败自动回退到任务原模型。

环境变量

  • 刷新 Windows 环境变量按钮：从注册表重新读取系统和当前用户环境变量，覆盖 Nova 启动时继承的同名变量。之后新启动的 agent 进程会用新值。

更新

Agent 配置

集中维护一份全局指令（如「始终使用中文；修改代码后执行聚焦测试；不要覆盖用户已有改动」）。Nova 会按已启用后端的原生规则入口分别适配。顶部显示集中配置文件路径（~/.nova/global-agent-instructions.md）。下方：

  • 全局指令文本域：编辑内容。「保存并同步」按钮。
  • 后端适配状态列表：每个已启用后端一行，可单独开关适配。显示状态（已同步/待同步/已取消适配）和文件路径。

清空后同步会移除 Nova 创建的托管文件/区块，不删各后端原有配置。正在运行的 Agent 需重启后读取新内容。

记忆检索

  • 启用语义检索勾选：关闭则用内置 BM25 关键词检索（零依赖）。
  • 服务地址：OpenAI 兼容的 base 地址。可填本地 Ollama（http://localhost:11434）、服务器地址、或任意 OpenAI 兼容的 /v1/embeddings 服务。
  • 模型名：中文/多语言推荐 bge-m3；轻量可用 nomic-embed-text。
  • API Key：本地服务留空；云端填对应 key。
  • 测试连接 / 下载模型（Ollama）按钮。

经验训练

  • 定期从新会话训练多个独立知识库勾选。
  • 训练模型选择器。
  • 训练间隔（分钟） / 世代演进间隔（分钟）：到间隔自动执行。
  • 经验专家配置：七个专家各可调写入率、更新率、遗忘率、迁移率。「重置为基础权重」按钮只恢复参数不删已有内容。

Worktree

  • worktree 根目录：留空 = 应用数据目录下的 worktrees/。可「浏览…」选择。改动仅对之后新建的 worktree 生效。
  • 已创建的 worktree 列表：每行显示分支 + 仓库名 + 漫游标签 + 路径 + 关联会话标题（或「无关联会话」）。右侧：「同时删分支」勾选框（直接检出已有分支的显示「已有分支」不可勾）+ 「移除」按钮。可「刷新」。

Skills

Skill 统一放在 ~/.nova/skills，启动各后端时会以软链接/目录联接同步到 Codex / Claude Code / Cursor / OpenCode / agents 的全局 skills 目录，不拷贝文件。

  • 顶部：集中目录路径（只读）+「打开」按钮（在文件管理器打开）+「同步」按钮（重新同步到各后端）。
  • 拖放区：拖入 zip 或 skill 文件夹安装（每个 skill 需含 SKILL.md）。也可「上传 zip…」「选择文件夹…」「刷新」。
  • 已安装列表：每行显示 skill 名 + 描述/路径 + 「删除」按钮。

外观

浅色 / 深色两套主题，点一下即换，选择自动记住。

高级

上下文机制

  • Cursor 上下文下拉：默认 / 超级（旧版超级上下文）。
  • 代码上下文检索下拉：无 / FastContext（默认，原生常驻服务 + 增量索引）。保存后重启相关 Agent 生效。

世界线

  • 启用 Checkpoint勾选：开启后从其他时间线继续对话会还原工作目录文件到对应时间点，默认关闭。

Windows 启动

  • Windows shell 启动 shim勾选：为 agent 子进程的 cmd/PowerShell/pwsh 使用无窗口 shim，减少控制台闪现。默认关闭，保存后重启 Nova 生效。

关于

  • 版本 + 「检查更新」按钮。
  • 会话管理：「批量管理会话」按钮展开列表，每行勾选框 + 标题 + 后端 + 项目。运行中的会话禁用勾选并标「运行中」。顶部「全选」+ 「已选 N 个」+「删除选中」按钮。
  • agent 日志：「查看 agent 日志（N）」链接展开最近 200 行日志，排障用。

附录

通知与防休眠

  • 任务完成通知：窗口不在前台时，任务结束（完成/出错/停止）会弹系统通知。Windows 点通知可唤起窗口并跳到对应会话；macOS 可通过 Dock 唤起应用。
  • 运行时防休眠：只要有会话在运行，系统不会因空闲自动休眠；所有会话结束后自动恢复。手动让电脑睡眠不受影响。

自动更新

新版本会在后台自动下载（侧边栏版本号可点击静默检查；下载中顶部徽章转圈，下载完变下载图标）。下载完成后在空闲时间（没有任何会话或任务在运行）弹更新弹窗，显示 v当前 → v最新 和大小。两个按钮：稍后 / 立即更新。点「立即更新」会替换并重启应用（进行中的任务会被打断）。不会强制静默重启。

排障

任务卡住一直转圈

通常是后端网络不通导致反复重试。按顺序尝试：

  1. 点输入框旁的停止按钮（或按 Esc）。若后端 10 秒内不响应取消，应用会强制结束本轮。
  2. 仍不行，去「设置 → 模型后端」底部「重启所有 agent 进程」，所有卡住的轮次立即结束，会话上下文下次发消息时自动恢复。
  3. 根治需保证网络能访问对应后端服务，必要时在「设置 → 模型后端」对应卡片的「代理」里填代理地址。

看到「Get-ChildItem: 找不到参数 la」之类的报错

这是 AI 在 Windows 上尝试了 Unix 风格命令（如 ls -la）后自行重试纠正，属于 AI 自身行为，不是 Nova 的问题，可忽略。

某个后端显示「未检测到 CLI」

对应命令行工具没装或不在 PATH 里。在「设置 → 模型后端」对应卡片的「可执行文件」里填完整路径，保存后会自动重新检测。

数据存在哪里

会话与设置统一保存在本地 ~/.nova/ 目录下，Windows 与 macOS 一致。
