# JEV DOM 决策

浏览器 DOM 操作默认委托 JEV。主模型负责把用户目标、授权范围、准确输入值和完成条件交给 `run`，处理视觉与异常，并核对最终结果。JEV 不接收截图、不推测坐标；桌面和 Canvas 内的视觉操作仍由主模型决策。

该规则在 Chrome/WebView 共用执行层落实，Lyra、CodeBuddy、Codex 等后端使用同一策略。JEV 开启后，主模型直接提交 DOM `click/fill/scroll`（含页面滚动和混合批次）会收到 `not_executed / jev_run_required`，整批未输入，原快照仍可用于 `run`。JEV 内部动作使用私有任务作用域，没有可通过工具 JSON 设置的绕过参数。

真实 `run` 交接时会刷新观察；只有 `jevRun.fallback.allowed=true` 才授予主模型一次单步 DOM 兜底，绑定同一会话、标签和返回的快照，180 秒有效。动作消耗快照，重新观察替换快照，都会取消该许可；之后恢复 `run`。无效计划或旧快照不会生成许可。视觉坐标、键盘等 JEV 不支持的操作仍由主模型完成，保留原有截图与焦点校验；关闭 JEV 时普通 `act` 不受限制。

## 执行循环

1. 从当前 DOM 枚举可操作元素，为每个候选分配本轮编号。候选携带名称、角色、所属区域、框架、表格列和状态；执行参数保留在本地。
2. JEV 选择编号，或返回 `done` / `defer`。不再按任务关键词自动裁剪候选，也不因按钮同名就删除候选。
3. 执行器使用真实 `frame/ref`，先激活明确绑定的 Chrome 标签以避免后台渲染限速，再沿用浏览器已有的节点身份、遮挡、焦点和输入结果校验。
4. 每次操作后重新获取 DOM。点击、滚动或页面变化后重新决策；完成判断还要经过一次新观察核验。
5. 模型不可用、证据不足、超出授权、执行不明确或预算耗尽时，返回最新观察、已执行历史及剩余目标，由主模型接手；不自动重放。

编号是交给模型的文字提示，类似 Vimium 的元素选择模式，不需要在网页上绘制标记。原有快照引用每次刷新都会改变；新增的文档内节点身份只用于判断计划是否仍适用，不能代替最新 `ref` 执行。

自定义文字控件的扫描额度只计入可见节点；隐藏和屏幕外的表格节点不能挤掉文档末尾新打开的菜单。仍沿用点击前的真实命中测试，DOM 中有编号不表示一定可以安全执行。

候选筛选参考 [Vimium LocalHints](https://github.com/philc/vimium/blob/5aa29614bf1dce05e0d316f8c38722e17f9b38c3/content_scripts/link_hints.js#L1124)：遍历 DOM 与生成操作提示是两件事。优先原生控件、交互角色及明确点击属性；普通 `tabindex` 容器不成为点击候选，包裹真实控件的语义 span 去重。为无语义的框架控件保留 `cursor:pointer` 边界回退，但不再把继承 pointer 的内部文字逐个编号。与 Vimium 一样保留可见性和命中检查；不同列或记录的同名控件仍是不同目标。

## 同屏路径

纯点击或滚动页面只判断当前一步；有可填写候选时，按字段数加一步、最多 4 个选择题推演路径。第一题始终只判断当前能推进目标的动作，不要求预知完整路径；后续题返回对应位置的候选。第一步必须来自本轮候选；后续回答只保留合法且不重复的前缀，重复、缺失或无效的后续题不作废已经有效的第一步。未知后续页面用 `defer` 截断路径。

目前只复用连续填写之后的剩余路径：每步刷新后，除预期字段值外，完整 DOM 状态必须一致，后续目标节点必须仍是原节点，并重新绑定最新引用。节点替换、验证提示、导航、菜单展开、遮挡和其他变化都会丢弃剩余计划。点击后的路径暂不复用；扩展它需要明确的动作后置条件。

## 边界

- 默认每次 `run` 最多 32 次动作，`maxActions` 可设 1–64，时间预算 180 秒。
- 每轮最多 256 个 DOM 候选；超过上限明确交接，可用 `controlNames` 主动缩小范围，不静默截断。
- 支持 DOM 点击、明确委托的填写，以及页面/内部容器的纵向滚动。输入值由主模型提供；同名且无法唯一绑定的输入框交回主模型。
- 视觉、敏感输入、不可逆操作、原生弹窗和不支持的交互由主模型处理。JEV 的文字建议不是视觉定位、操作授权或业务成功证明。
- `jevRun.requestCount` 记录实际请求，`cachedActions` 记录通过新 DOM 校验后复用路径的决策次数；`history` 用于核对已执行操作。

## 检查

`cargo test --manifest-path src-tauri/Cargo.toml --lib jev` 检查候选、路径协议和状态校验；`node scripts/browser-precision.test.mjs` 在真实 Chromium 中检查节点身份与浏览器操作保护；工具描述变更后运行 `npm run build:nova-tools-mcp` 和 `node --test scripts/automation-schema.test.mjs`。

这些自动检查不调用线上 JEV。dev 真实页面验证见 [实测记录](jev-dom-live-test.md)，多题推演的命中率以实际 `cachedActions` 为准。
