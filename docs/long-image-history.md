# 长会话与多图历史

## 日常展示与原始记录分离

聊天页使用 `get_thread_page`（默认 80 项、512 KiB，接口上限 128 项/1 MiB），前端保留最多 240 项、保守 UTF-8 估算 1.5 MiB 的连续窗口。向上/下滚动边缘或点击分页按钮读取相邻片段；回到最新消息读取尾页。翻页保留消息锚点，移出的条目只退出界面内存，不删除源历史。单条大消息显示显式截断提示，点击后按需读取完整消息；超长全文分段挂载，复制读取原文。截断预览不会作为完整提示词保存到复用菜单。

`get_thread` 保留给显式导出和工作流上下文，不用于普通会话切换、刷新和漫游重同步。分页窗口不能用于覆盖后端历史。合计 token/轮数使用后端整条历史的统计，而非窗口局部求和。世界线需展开才请求检查点和提示词目录；使用固定长度节点标识和迭代构图，DOM 仅挂载当前可见节点。产物面板按需读取全历史的路径索引，不因分页漏掉老文件；过大的索引明确提示截断，原记录仍可访问。

## 流式更新和发送/停止

浏览器不再订阅包含图片的原始 `acp:update`；原事件为远程/漫游兼容继续保留。原生工作线程将其合并为 `acp:history` 的 ID 失效通知，界面分批（每次最多 16 ID）读取当前权威投影。相同通知重复到达不会叠加 delta。切换会话、分页与请求响应都按代次校验；结构恢复使旧游标失效并重新加载。阅读旧记录时后台新消息只更新最新位置标记，不挤走阅读窗口。发送新的提示词才主动回到最新；乐观气泡按权威用户记录确认消除。

停止优先找正在运行的 manager/取消句柄，不因日常大历史复制而等待 ThreadStore；界面立即显示“正在停止”，去重相同请求。取消调用返回不等于模型已经停止，不伪造 running=false。页请求挂起不拦截取消 IPC。异常恢复/写盘错误不自动重放编辑动作，只对后端明确的“会话正在运行”预检拒绝短暂重试。

## 图片

普通页面只携带短图片引用，支持用户附件、Markdown 本地/内嵌图，以及嵌套工具图片。原生缩略图限流 2 个解码任务，按需生成 480/960/1536 边长版本；前端只排队可见图片，最多 2 个并发，最多 48 个条目/32 MiB 解码位图，离开会话释放位图且旧异步响应不会复活旧缓存。一条消息有很多图片时也逐图判断可见性。图像尺寸元数据独立于位图保留；仅尺寸变化时重排，解码完成通常只重绘。

原图按 SHA 内容地址保存并校验，缩略图不替代模型输入、复制/分享原始附件或原图预览。单独点开原图才读取原分辨率。特殊巨大图片超出预览解码预算会返回错误而不是耗尽预览资源。远程 URL/未落盘的乐观粘贴图片保留兼容路径，可能仍需短暂解码源图；位图留存预算不等于整个进程 RSS 上限。

## 存储与安全升级

`TranscriptItems` 使用每块 32 项的写时复制共享数据。后台保存只序列化脏块，未变块复用 SHA 文件，锁内只取共享快照，昂贵序列化、图片迁移和写盘在 blocking worker 中完成。内嵌用户和工具附件渐进外置；失败保留内嵌原件。并发修改时只采用仍未变的迁移块。助手 Markdown 中的内嵌图仍可能留在原文中，展示时替换短引用，不宣称源历史/全进程内存完全不随记录增长。

每个会话的 JSON 变为 `nova-history-chunks-v1` 清单，引用不可变 chunks。先写完整块再发布清单；首次迁移保留 `.json.pre-chunks` 原文件，后续保存保留 `.json.previous` 完整清单。损坏清单尝试上一完整版本；分块缺失或校验失败不能当成空历史。共享资源不由单会话删除直接清理，以免破坏世界线/回收站引用。

**升级前备份整个 Nova 数据目录。旧版不能直接读取新清单，不可只替换 EXE 盲目降级。** `.pre-chunks` 是迁移时点备份，不含迁移后的新消息；需要降级时先用新版导出当前完整记录并验证，或恢复整个升级前备份并明确后续数据差异。当前没有自动资源垃圾回收，历史分块及图片可能增加磁盘占用。

## 验证入口和边界

```
npm run check
node --experimental-strip-types --test scripts/history-window.test.mjs scripts/history-images.test.mjs scripts/bubble-image-layout.test.mjs
node scripts/history-ui.test.mjs
cargo test --manifest-path src-tauri/Cargo.toml --lib history_
cargo test --manifest-path src-tauri/Cargo.toml --lib transcript::
cargo test --manifest-path src-tauri/Cargo.toml --lib threads::
cargo test --manifest-path src-tauri/Cargo.toml --lib time_machine::
```

`history-ui.test.mjs` 挂载真实 ChatView/Composer/CanvasTranscript，模拟原生边界：10,000 轮（40,000 项）逻辑历史、短图片引用、实际 PNG 缩略图解码、请求竞争与发送/停止。计数中的原图片字节是模拟统计，不是向测试浏览器真的塞入几十 GiB 图片。`TEST_OFFLINE=1` 用离线打包页面，默认使用实际 Vite/HTTP 浏览器；均不修改浏览器管理策略。

Windows `history-native-smoke.mjs` 只对一次性 NOVA_DATA_DIR 工作，真实启动 Nova/WebView2、读取 1,200 轮和 800 个内嵌图记录、通过真正 Rust IPC 生成缩略图并验证原件身份、检查迁移备份和重启恢复。需要仅在 CI debug 副本中配置回环 CDP 驱动，产品配置不得开启。该测试不调用收费提供方，取消测试不声称验证所有在线模型的实际终止延迟。

CI 的 `Long-session regression` 执行上述及已有长文本/终端/工作区测试。具体通过/失败与耗时以对应提交的 Actions 日志为准。没有用户那条真实会话的性能录制，不承诺任意数据零卡顿或固定提速倍数。显式全文、全历史导出、世界线历史快照和全尺寸原图仍可能消耗较多资源，普通聊天展示不等待它们。
