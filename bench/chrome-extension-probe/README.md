# Chrome 扩展可行性验证

独立验证，不接入 Nova 产品，不使用 Playwright，不开启 Chrome 调试端口，不重启 Chrome。

1. 在仓库根目录运行 `node bench/chrome-extension-probe/probe.mjs`。
2. 在 `chrome://extensions` 开启开发者模式，点击「加载已解压的扩展程序」，选择输出的 `extension` 目录。安装会申请 debugger/tabs/storage 权限。
3. 点击 Chrome 工具栏的扩展图标，打开「Nova Chrome 验证助手」，点击「打开测试页」。只保留一个测试页。
4. 再次打开扩展，点击「运行验证」。面板会显示结果及报告是否回传；报告在 `out/report.json`，截图在 `out/screenshot.png`。助手可直接读取，无需复制日志。
5. 完成后卸载临时扩展、关闭测试标签，停止脚本。脚本2小时后自动退出。重新启动会复用原地址、凭证和测试页。修改扩展代码后，在 Chrome 扩展管理页点击「重新加载」。

网络失败不影响浏览器检查结论；完整报告先保存在扩展本地，可点击「仅重试报告回传」，不会重放页面操作。旧版本未保存的截图无法补回，补传摘要会明确标记截图缺失。后台运行接收端时应使用独立进程并重定向日志，避免终端会话关闭时丢失服务。

只允许操作本次生成的精确 localhost 测试 URL。复用 Nova 原生浏览器的 DOM 观察脚本；检查已有页面与存储状态、屏幕外 DOM、真实中文输入/点击、截图、弹窗标签、切换状态和断开重连。报告仅发送到本机，校验扩展 Origin 和随机凭证。

此原型使用一次性 HTTP 回传验证扩展与本机通道，不代表已验证生产 WebSocket 连接、跨域 iframe、MV3 长时间恢复或真实网站任务性能。

服务启动后运行 `node bench/chrome-extension-probe/self-check.mjs` 检查打包、测试页面和接收端鉴权。该检查不会生成成功报告；只有实际扩展运行才会生成报告。
